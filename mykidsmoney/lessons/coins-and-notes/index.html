Coins & Notes

New Zealand money comes in different coins and notes — each worth a different amount.

Coins

New Zealand coins

New Zealand uses five coins: 10c, 20c, 50c, $1 and $2. Each one is worth a different amount, and it's worth learning them by their value — not just how they look.

An important idea

A bigger coin isn't always worth more

It's the number on the coin that matters, not its size. For example:

Notes

New Zealand notes

For bigger amounts, New Zealand uses notes instead of coins: $5, $10, $20, $50 and $100.

Adding it up

Counting money

Once you know the values, counting money is just adding them together.

2 × $1 = $2
5 × $1 = $5
$2 + $1 + $1 = $4
$5 + $2 = $7
Same value, different pieces

Money has value, not just pieces

What matters is the value, not how many coins or notes you're holding.

Five $1 coins
$5
One $5 note
$5

They look completely different, but they're worth exactly the same amount. That idea matters later too — it's the same reason $1 in a bank account is still real money, even though it doesn't look like a coin.

A quick example

Making change

$5You have $5.
−$3You buy something for $3.
$2You pay $5, get $2 change, and still have $2 left.
Try it yourself

Can you make it?

Grab some real coins if you have them, and have a go before checking an answer.

Can you make $3?

One way: $2 + $1. Another way: three $1 coins.

Can you make $5 in two different ways?

Try one $5 note, or $2 + $2 + $1 — both equal $5.

Can you make $7 using coins and notes?

One way: a $5 note + a $2 coin. There are other combinations too — see how many you can find.

Adapting it

For different ages

Younger children

  • Identify each coin
  • Recognise their values
  • Count simple amounts

Older children

  • Combine different coins and notes
  • Make the same amount in different ways
  • Work out simple change
  • Compare prices
For parents

Give your child a small handful of real coins, and ask them to:

  1. Sort the coins.
  2. Identify each value.
  3. Count how much they have altogether.
  4. Try making different amounts with the coins.

Everyday moments work well for this too — no need to set aside a lot of money:
